First time using OBS?
  1. In OBS, add a Browser Source and paste this URL.
  2. Set its width and height to your scene dimensions. Match OBS → Settings → Video → Base (Canvas) Resolution to those dimensions.
  3. Or download the scene and choose Scene Collection → Import in OBS.
  4. Use Publish to /live in the Layout editor when your scene is ready. Start your broadcast in OBS.
